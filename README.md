🌎 Around The U.S.

📌 Descrição do Projeto O Around The U.S. é uma aplicação web interativa desenvolvida com foco em experiência do usuário e manipulação dinâmica de conteúdo. A plataforma permite visualizar, criar e gerenciar cartões de locais turísticos, simulando uma interface de compartilhamento de viagens.

O projeto apresenta uma interface moderna, com funcionalidades dinâmicas como edição de perfil, adição de novos cards e visualização de imagens em modal, proporcionando uma experiência fluida e intuitiva.

🎯 Objetivo do Projeto Este projeto foi desenvolvido com o objetivo de fortalecer habilidades em desenvolvimento front-end, especialmente:

Manipulação avançada do DOM com JavaScript Criação de interfaces dinâmicas e interativas Estruturação semântica com HTML5 Estilização organizada com CSS3 e metodologia BEM Implementação de boas práticas de desenvolvimento

Além disso, o projeto simula funcionalidades reais de aplicações modernas, contribuindo para a construção de um portfólio sólido.

🚀 Funcionalidades

✏️ Edição de perfil (nome e descrição) ➕ Criação de novos cartões com imagem e título ❤️ Sistema de curtidas (like) interativo 🗑️ Remoção de cartões dinamicamente 🖼️ Visualização de imagens ampliadas em modal ⚡ Renderização dinâmica de elementos via JavaScript 📱 Interface responsiva e intuitiva

🛠 Tecnologias Utilizadas

HTML5 → Estrutura semântica da aplicação CSS3 → Estilização e layout (Flexbox e BEM) JavaScript (ES6+) → Lógica, eventos e manipulação do DOM Git & GitHub → Versionamento e gerenciamento do projeto

📚 Aprendizados e Destaques Técnicos

Durante o desenvolvimento deste projeto, foram aplicados conceitos importantes como:

Manipulação eficiente do DOM Criação de componentes reutilizáveis Uso de para renderização dinâmica Controle de eventos (click, submit) Separação de responsabilidades no código Boas práticas de organização com metodologia BEM
